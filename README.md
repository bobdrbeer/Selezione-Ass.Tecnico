# 🏆 Tecnico migliore del mondo — Emanuele Casu

Mini-sito scherzoso statico per GitHub Pages.

## File

- `index.html` — struttura della pagina
- `style.css` — grafica e animazioni
- `script.js` — logica del sondaggio e gag

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository su GitHub.
2. Carica questi tre file nella cartella principale del repository.
3. Vai in **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona il branch `main` e la cartella `/ (root)`.
6. Salva e attendi la pubblicazione.

Non serve PHP, database o server: funziona interamente nel browser.

## Personalizzazione

I nomi degli altri tecnici si modificano direttamente in `index.html`.

Le battute e il comportamento dei pulsanti si modificano in `script.js`.

Il sito non raccoglie né invia dati personali.
